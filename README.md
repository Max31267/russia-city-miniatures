# Миниатюры городов России

План веб-приложения для создания физических миниатюр по выбранному участку карты России. Пользователь выделяет область, проверяет объёмную модель и скачивает **один STL-файл** для 3D-печати всей миниатюры.

**Состояние проекта:** работает первая браузерная версия генератора; ниже сохранены требования, архитектура и критерии готовности.

## Запуск

```sh
npm ci
npm run dev
```

Для проверки геометрии: `npm test`. Для сборки сайта: `npm run build`.
При публикации из `main` GitHub Actions выполняет тесты, сборку и выкладывает сайт на GitHub Pages.

## Требования

1. Пользователь выбирает прямоугольную область на карте. Начальный размер — 400 × 400 м, предельный — 600 × 600 м.
2. Макет содержит реальный рельеф местности, здания, различимые по высоте дороги и водоёмы, прямоугольное основание и рамку. Надпись на рамке необязательна.
3. Доступны 3D-предпросмотр, настройка длины наибольшей стороны макета от 100 до 220 мм (начальное значение — 180 мм), усиление рельефа от 1× до 5× (начальное значение — 1×) и ручная правка высоты отдельного здания.
4. Высота здания определяется по `height`, затем по `building:levels × 3 м`. Если оба значения отсутствуют, используется приблизительная высота 9 м. Интерфейс показывает число зданий с приблизительной высотой.
5. Экспортируется один бинарный STL в миллиметрах: единый замкнутый объём с основанием толщиной не менее 3 мм и шириной печатаемых деталей не менее 0,8 мм. STL не содержит цвета; цвета в предпросмотре служат для различения объектов.
6. Если картографические данные или данные рельефа недоступны, приложение объясняет ошибку и предлагает повторить загрузку. Экспорт неполной модели недоступен.

## Архитектура

Приложение работает в браузере без собственного сервера и размещается на GitHub Pages. Исходный код — TypeScript, сборка — Vite. MapLibre показывает карту и область выбора; Three.js показывает 3D-предпросмотр.

Геометрия зданий, дорог, водоёмов и зелёных зон поступает из [OpenStreetMap](https://www.openstreetmap.org/copyright) через [Overpass API](https://wiki.openstreetmap.org/wiki/Overpass_API). Если Overpass недоступен, браузер запрашивает небольшой участок непосредственно через API OpenStreetMap. Данные о высоте земли поступают из [Mapzen Terrain Tiles на AWS](https://registry.opendata.aws/terrain-tiles/) в формате Terrarium. Запросы выполняются после подтверждения выбранной области; размер области ограничен, чтобы не перегружать публичные сервисы.

Web Worker преобразует координаты в локальные метры, интерполирует рельеф и строит сетку основания. Дороги и воду он отображает неглубокими углублениями; здания и рамку — объёмами, соединёнными с основанием. [Manifold WASM](https://github.com/elalish/manifold) объединяет детали в одну замкнутую модель, из которой создаётся бинарный STL. Предпросмотр использует ту же геометрию, что и экспорт.

Интерфейс указывает источники и лицензии картографических данных и рельефа. Сборка и публикация сайта на GitHub Pages выполняются через GitHub Actions после появления первой рабочей версии.

## Проверка готовности

- Выбор области и построение модели работают для плотного городского квартала, участка со склоном и участка со зданиями без известных высот.
- Ручное изменение высоты здания отражается в предпросмотре и экспортированном STL.
- STL представляет собой одну замкнутую оболочку без открытых рёбер, сохраняет минимальную толщину основания и открывается в слайсере как один печатаемый объект.
- Опубликованный сайт загружает карту, OSM и рельеф из обычного браузера на GitHub Pages; ошибки внешних сервисов отображаются понятно и не создают неполный STL.

## Этапы

1. Опубликовать этот план в публичном репозитории и пригласить соавтора `Zaqvierm`.
2. Создать выбор области, загрузку данных и 3D-предпросмотр.
3. Добавить подготовку геометрии, проверку модели и экспорт STL.
4. Протестировать печатный файл в слайсере и опубликовать сайт на GitHub Pages.

Код проекта распространяется по лицензии MIT; данные OpenStreetMap и рельефа сохраняют собственные условия использования и требования к указанию источника. Точность высот зданий и рельефа зависит от исходных данных. Перед физической печатью проверьте STL в слайсере.
